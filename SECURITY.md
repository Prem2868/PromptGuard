# Security Policy

## Scope

PromptGuard is a defensive research tool for identifying prompt-injection and jailbreak indicators. It is not a guarantee that text is safe and should not be used as the only control for high-impact decisions.

## Reporting a vulnerability

Please do not disclose exploitable details in a public issue. Report security issues privately through the repository's GitHub **Private vulnerability reporting** feature, or contact the maintainer through the email listed on the maintainer's GitHub profile.

Include the affected version or commit, reproduction steps using a harmless fixture, expected and actual behavior, and any suggested mitigation. Please allow reasonable time for investigation before public disclosure.

## Safe use

Use this project only for systems, prompts, and data that you own or are explicitly authorized to assess. Do not include secrets, personal data, or live attack targets in issues, pull requests, tests, or logs.
